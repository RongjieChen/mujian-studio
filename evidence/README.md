## 已观察到的失败

Nemotron-3-Nano-30B-A3B 的自转换 Q4_K_M 版本能够调用 Pi 工具，但早期案件生成出现缺失人物引用、证词没有来源和问话前置条件不匹配；尚不能据此认为它适合直接承担中文案件编排。我们收紧了工具数据契约、增加局部修改工具、让检查器指出缺少的前置证据，保留所有失败，不将人工修好的样本标为模型独立完成。

两个调试请求因 SSH 隧道断开失败。把 Node 工作台移至 Spark 本机后，后台任务不再依赖调试隧道持续连接。上述网络错误不能计为 GPU 或模型质量错误。

量化预设名 Q4_K_M 不等于每个参数平均恰好 4 bit：本次 Nemotron 文件约 23,371.92 MiB，量化日志报告 6.21 BPW。日志出现约 75 token/s 的解码片段，尚不是规范吞吐基准。
