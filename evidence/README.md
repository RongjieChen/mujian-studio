# 实测记录

运行日期：2026-09-21（北京时间）。本目录保留开发过程中的成功与失败记录，不能把经过调试后的个例当成整体成功率。

## 测量边界

- 工作站：单台 DGX Spark，NVIDIA GB10，Linux ARM64，119 GiB 可见统一内存，驱动 580.159.03、CUDA 13.0。
- llama.cpp：b11062 / 3cf03257f219afbe7334045ff7c6a06ac68c627d，CUDA SM121a。
- Pi：0.86.1。固定检查器负责结构与可达性判断，模型不能修改检查器。
- 自动测试：18 项通过，包括通关路径重放、证据条件、死锁、错误指认、版本冲突、缓存失效、导出复查及 HTML 转义。
- 开发初期的工作台在 Mac 上，通过隧道访问 Spark；后续工作台、模型和素材服务迁移到同一台 Spark。记录时区为 UTC。

## 已观察到的失败

Nemotron-3-Nano-30B-A3B 的自转换 Q4_K_M 版本能够调用 Pi 工具，但早期案件生成出现缺失人物引用、证词没有来源和问话前置条件不匹配；尚不能据此认为它适合直接承担中文案件编排。我们收紧了工具数据契约、增加局部修改工具、让检查器指出缺少的前置证据，保留所有失败，不将人工修好的样本标为模型独立完成。

两个调试请求因 SSH 隧道断开失败。把 Node 工作台移至 Spark 本机后，后台任务不再依赖调试隧道持续连接。上述网络错误不能计为 GPU 或模型质量错误。

量化预设名 Q4_K_M 不等于每个参数平均恰好 4 bit：本次 Nemotron 文件约 23,371.92 MiB，量化日志报告 6.21 BPW。日志出现约 75 token/s 的解码片段，尚不是规范吞吐基准。

## 尚不能声称的结果

长期稳定性、创作者节省工时、总体成功率、Skills 消融收益、跨镜头人物一致性及硬件总成本都需要额外实验。日志里的模型 API cost=0 仅表示未向云端按 token 支付费用，不包含机器、电力、存储、开发和返工成本。

手工示例和预制 SVG 始终单独标记。视频的首次调用缺少 ftfy 依赖，在加载后失败；现已把 ftfy 固定写入安装清单，原失败记录保留。

## 新案件与死锁修复

- 全新《童谣谜案》：Pi 任务耗时 258,220 ms，初稿缺少一条证词来源，模型依据检查结果自行补全后提交。rulesVersion=2 通过，六条证据、12 步检查器路径重放成功。人工浏览器操作也验证了证据不足时不出现追问、取得两项物证后解锁证词，以及正确结案。本次生成途中没有人工替写草稿。
- 《陨石疑云》编辑：386,684 ms，包含人类指出动机与证词要求后的修改，不能算无反馈的一次成功。
- 死锁修复：把 fake_stone 的 requires 改成自身后，实际导出返回 HTTP 409。Pi 修复任务耗时 153,019 ms，仅移除这一自引用；代码检查确认 truth 完全相同，其他案件字段不变。第 4 版独立重放成功，实际导出 HTTP 200。见 runs/deadlock-repair-verification.json。
- 两个通过的案件仍存在文学性与现实逻辑需要作者润色的问题。结构检查不证明案件有趣、动机合理或游戏时长达到十分钟。

以上 Agent 时间从 startedAt 到 finishedAt，排除队列等待，但包含其任务内模型调用与工具处理。原始时间字段可用于重算。

视频第二次调用触发 Diffusers 0.35.2 的 Wan 2.2 VAE 分块通道错误；与上游 [#12113](https://github.com/huggingface/diffusers/issues/12113) 相符。关闭该分块路径后第三次调用成功，两次失败均保留。Qwen3.6 候选权重下载已暂停，未进行推理测量。

## 独立播放器与最终部署

在独立静态页面载入《雨停之前》的单文件 HTML 后，使用浏览器开发协议切为离线，仍可搜集全部六条证据、解锁证词并到达正确结局；人物 MP4 以 data URL 内嵌，离线时 readyState=4、paused=false。测试后恢复该页网络。见 runs/browser-offline-export.json。之后第 4 版仅人工调整茶室现场描述，使人物位置与参考画面一致；案件规则与镜头输入保持不变。

最终代码在 Mac 与 Spark 均通过 18 项测试及完整构建。工作台重启后，三个已保存项目、修订与四份当前可用媒体仍可读取，活动任务数为 0。尚未实施长时间压力测试或整机断电恢复实验。
