## 2026-09-21 环境与样本

硬件为 DGX Spark / NVIDIA GB10，Linux ARM64，119 GiB 可见统一内存，驱动 580.159.03、CUDA 13.0；语言服务为 llama.cpp b11062（提交 3cf03257f219afbe7334045ff7c6a06ac68c627d），Pi 0.86.1。部分应用请求通过 Mac 至 Spark 的隧道执行，服务位置以记录为准。

| 样本 | 参数或结果 | 应用作业耗时 |
|---|---|---:|
| SDXL 首图 | 1024×576，20 步；加载 36.687 秒 | 42.490 秒 |
| SDXL 热态下一图 | 同进程、无模型加载 | 4.299 秒 |

Wan 作业 `144d15cb-419b-4d16-81f0-871184447704` 的 worker 耗时 183.559 秒，其中加载 94.761 秒；其余部分包含编码、采样、解码与封装。PyTorch 峰值已分配约 30.04 GiB，在加载后重置计数，不代表整机峰值。参考图及第 0、24、48 帧位于 `media/`。

该批次 Qwen3-Next-80B-A3B-Thinking 使用 F16 转换的 Q4_K_M GGUF，约 47,258.42 MiB、4.87 BPW，SHA256 为 `1624acebd3e14f320d5e9c9dd8a2c78698ee5fa15e7e6f06e81077c6444a4c49`。

## 失败样本与测量边界

原始日志包括缺失人物引用、证词来源错误、问话条件不匹配、网络断开、缺少 ftfy 和 Wan VAE 分块通道错误。不同失败原因分别记录，不能都算作模型质量错误。Nemotron 的部分工具调用成功，也存在中文案件生成失败。

这些是少量开发样本，同题反馈后的修改不属于首次生成成功，单次热态延迟不代表所有请求。完全相同的图片请求可命中缓存，日志中的原素材耗时与本次缓存响应耗时含义不同。

独立播放器离线调查与结案见 `runs/browser-offline-export.json`。技术验证范围不包含整体创作成功率、真人效率、长期稳定性、跨镜头人物一致性或硬件总成本；模型 API cost=0 也不表示没有机器、电力、存储和返工成本。
