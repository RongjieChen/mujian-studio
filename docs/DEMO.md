# 幕间参赛演示入口

正式录制使用 [逐镜画面、操作与口播脚本](VIDEO-SCRIPT.md)，实际完成状态使用 [交付验收](RELEASE-AUDIT.md)，测试范围使用 [对抗测试说明](TESTING.md)。这三份文档与当前实测同步，替代早期的“下一轮验收计划”。

推荐展示顺序：试玩成品 → 真实新题创作 → 局部修改与版本 → 故意注入死锁并修复 → 叙事矛盾初审 → Spark 镜头与缓存 → 独立 HTML 离线结案。

叙事初审可能误报，图片细节可能偏离提示。演示中保留这些边界；手写示例、作者反馈后的修订、此前生成的镜头、缓存命中和本次推理分别标记。

需要公开提交的资料见 [参赛材料](SUBMISSION.md)。公开仓库、B 站上传、团队照片和表单提交由所有者完成，不将准备好的文案写成已经发布。
